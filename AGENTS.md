# Project instructions

Every assistant-made change to this project must include updates to both change logs in the same task:

- `CHANGES_TECHNICAL.md`: detailed request, resulting changes, affected files, validation, and remaining limitations.
- `CHANGES.md`: concise, easy-to-read dated summary.

Use America/New_York dates and put new entries first. Apply this requirement to code, configuration, documentation, and project-instruction edits. Answers that do not change files do not need log entries. Never record secrets or personal email contents. Do not claim browser testing or external setup was completed without evidence.

Keep the table of contents in `CHANGES.md` updated with a hyperlink for every dated section.
