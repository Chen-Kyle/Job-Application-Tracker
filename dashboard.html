Set up Gmail access

Create a Google Cloud project, enable Gmail API, and add yourself as a test user. Create a Chrome Extension OAuth client using this extension ID: .

Add the following top-level field to manifest.json, replace the client ID, and reload the extension:

"oauth2": {
  "client_id": "YOUR_CLIENT_ID.apps.googleusercontent.com",
  "scopes": ["https://www.googleapis.com/auth/gmail.readonly"]
}

See docs/GMAIL_SETUP.md in the extension folder for the complete steps.
